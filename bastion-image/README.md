# Bastion scene illustrations

One new illustration accompanies each game-master story message. Number files in story order, for example `001-the-bell-beneath-bastion.png`. The canonical scene and loop record is [CAMPAIGN.md](../CAMPAIGN.md).

Art direction: atmospheric ink-and-gouache industrial fantasy, human scale, crooked architecture, tarnished brass, damp stone, smoke, and a few vivid lights. Images illustrate the moment without determining the player's action or revealing hidden answers.
